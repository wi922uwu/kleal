# Монетизация — этап 1 (локально, 7 октября 2026)

## Границы реализации

Это основа тарифного flow, **не готовый платёжный релиз**. Реальные списания,
магазины приложений и новые ограничения продукта не включены. Production не менялся.
Использован свежий read-only снимок `/opt/kleal`: HEAD
`84a751c0a54477619593f623add962691557f983` плюс фактические серверные изменения.
Исходный снимок и SHA-256 находятся в `.codex/baseline` и `.codex/baseline-manifest.json`.

Экран: **Настройки → Kleal Plus**. Локализация RU / EN / ES.

1. Загрузка статуса с сервера; при ошибке — понятная ошибка и повтор запроса.
2. Free, Preview либо завершённый Preview. При выключенном серверном флаге запуск недоступен.
3. Выбор месячного/годового варианта: ориентиры из PDF — €11,99 и €89,99.
   Это не цена из магазина и не предложение совершить оплату.
4. Явное согласие на тестовый Preview → сервер начинает 14 суток.
5. Срок сохраняется между входами/устройствами и не продлевается повторами.
6. После истечения сервер возвращает Free. Покупка отключена; восстановления покупок пока нет.

Preview здесь меняет **только тестовый статус**, а не разрешения продуктовых действий.
Автоматический старт при первом значимом действии из PDF пока не реализован:
нужно согласовать, какое событие его запускает и как учитывать существующих пользователей.
Старые Plus-плашки и клиентский лимит диалогов пока не мигрированы на новый экран.

## API

Все ручки используют существующий gateway-prefix `/api/onboarding/monetization`.
Доступ — по Bearer-сессии через общий `kleal_auth.caller_person(strict_storage=True)`.
Владение — стабильный `users.id`; имя, ID из тела и параметры URL не выбирают владельца.

| Метод | Путь | Тело | Результат |
|---|---|---|---|
| GET | `/status` | — | Текущий статус + каталог ориентиров |
| POST | `/preview` | `{"consent":true}` | Одноразовый Preview или тот же существующий срок |
| POST | `/purchase` | `{}` | 409 `store_not_configured`, ничего не начисляется |
| POST | `/restore` | `{}` | 409 `store_not_configured`, ничего не начисляется |

Неизвестные поля / неверный тип согласия — 400, нет сессии — 401,
выключенный Preview — 409, недоступное хранилище — 503. Ответы `Cache-Control: no-store`.
Ни редирект, ни локальный флаг, ни поддельная квитанция не дают платный статус.

## Хранение и локальное включение

По умолчанию Preview **OFF**: GET не создаёт БД, POST не пишет данные.
Для отдельного тестового экземпляра onboarding нужно явно задать:

```sh
KLEAL_MONETIZATION_PREVIEW_ENABLED=1
KLEAL_MONETIZATION_DB=/absolute/path/to/isolated-preview.sqlite3
```

Родительский каталог должен существовать; сервис не создаёт его самостоятельно.
SQLite хранит только `person_id`, `started_at`, `expires_at` в UTC Unix seconds.
Первичный ключ + транзакция защищают от двойного запуска с нескольких устройств.
Истечение вычисляется на сервере, фоновой задачи для перехода в Free не нужно.
Повторное включение флага не обнуляет ранее использованный срок.

Это временное хранилище для одного тестового сервиса, **не итоговый биллинг-контур**.
До массового включения нужны согласованные миграции/резервное копирование,
очистка при удалении аккаунта и политика хранения истории использованного Preview.
Отключение флага не удаляет записи, не меняет встречи/переписки и не отключает KYC.

## Проверки

```sh
KLEAL_DB=json python3 -m unittest discover -s kleal-ms/tests -p 'test_monetization*.py' -v
node kleal-app/tools/monetization_test.js
node kleal-app/tools/identity_test.js
cd kleal-app
node node_modules/typescript/bin/tsc --noEmit
CI=1 EXPO_OFFLINE=1 node node_modules/expo/bin/cli export --platform ios --output-dir ../.codex/export-ios
CI=1 EXPO_OFFLINE=1 node node_modules/expo/bin/cli export --platform android --output-dir ../.codex/export-android
```

Серверные тесты запускают реальные обработчики onboarding и `KlealServer` на loopback,
синтетические аккаунты и временную БД. Нет обращений к платёжным провайдерам.
Клиентские тесты выполняют контроллер и валидатор, но не подменяют native QA.

Локальный результат: 15/15 новых серверных и 10/10 клиентских тестов прошли;
identity 25/25, session 6/6, account-switch 6/6, Google/Apple/OAuth — PASS.
TypeScript — PASS. Expo iOS: 1913 модулей; Android: 1994 модуля, оба экспорта PASS.
Точечный diff относительно снимка — 11 файлов; из существующих изменены только
`app/_layout.tsx`, `src/settings.ts` и `services/onboarding/app.py`.
Патч: `.codex/monetization-phase1.patch`; команды и логи: `.codex/qa/`.

Известные исходные ошибки до этой правки:

- `tools/regressions_test.js`: три проверки нормализации интересов, выполнение далее прерывается.
- `services/onboarding/test_interest_normalization.py`: две проверки интересов.
- Общий `git diff --check` относительно старого Git HEAD: whitespace в `app/create.tsx`
  и `services/buddy/app.py`, уже присутствующий в серверном снимке.

Эти проверки не отключались и не ослаблялись. Полный проект нельзя объявлять зелёным.
Экспорт JS-бандлов не равнозначен тесту на физическом iOS/Android устройстве.
