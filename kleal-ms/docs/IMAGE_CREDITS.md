# Image credits

Cover photographs on the intent cards. Every file is public domain, CC0 or CC BY-SA and is used
commercially under those terms; the CC BY-SA ones require this attribution, which is why this file
is shipped rather than left in a ticket.

Fetched from **Wikimedia Commons**, centre-cropped to 2:1 and re-encoded to 480x240 JPEG. Sources
are curated Commons CATEGORIES, not free-text search: Commons ranks for documentary material, and
a text search for a coffee shop returned fire trucks while one for an art museum returned a Rubens.

The 37 topic keys the cards can carry collapse onto these covers — at 96px tall a tennis court says
nothing a football pitch does not, while coffee vs mountains vs a concert read instantly.
